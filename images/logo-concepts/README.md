# HVACoder logo concepts

These images preserve exploratory logo concepts developed during design discussion. They are reference material only and do not establish an adopted HVACoder brand standard or final logo.

The concept is an HVAC fan whose airflow transitions into binary data. The intended 8-bit ASCII payload for `HVACoder` is:

`01001000 01010110 01000001 01000011 01101111 01100100 01100101 01110010`

Some generated variants include additional decorative binary around the intended sequence; image-generation output should not be treated as a byte-accurate encoding unless separately verified.

## Variants

- `01-initial-binary-breeze-wordmark.webp` — early fan + digital-airflow wordmark concept.
- `02-binary-airflow-wordmark.webp` — binary grouped more explicitly along the airflow.
- `03-flowing-binary-wordmark.webp` — smoother airflow concept with binary partially embedded in surrounding digits; favored direction during exploration.
- `04-digital-airflow-wordmark.webp` — denser digital-airflow treatment.
- `05-icon-only-digital-airflow.webp` — icon-only fan and digital airflow.
- `06-earlier-full-logo-reference.webp` — earlier full-logo reference retained from the design session.

These are optimized reference copies preserved from the conversation, not production-ready master artwork.
